# Minimal Landing Page (HTML/CSS)

Landing page minimalista desarrollada con HTML y CSS, enfocada en un diseño limpio y responsive.

## Características
- Layout responsive (mobile/desktop)
- Secciones claras y jerarquía visual
- Estilos organizados y estructura simple
- Assets ordenados (imágenes/íconos)

## Tecnologías
- HTML
- CSS
